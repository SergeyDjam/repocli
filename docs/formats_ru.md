# Форматы файлов

## RPM-пакет (входные данные)

### Lead

Первые 96 байт:

| Смещение | Размер | Значение |
|---:|---:|---|
| 0 | 4 | магия `ed ab ee db` |
| 4 | 1 | старшая версия (заморожена на 3 даже у rpm6) |
| 5 | 1 | младшая версия |
| 78 | 2 | тип сигнатуры (big-endian) |

### Заголовок

Заголовок сигнатуры и основной заголовок имеют одинаковую структуру:

| Смещение | Размер | Значение |
|---:|---:|---|
| 0 | 4 | магия `8e ad e8 01` |
| 4 | 4 | зарезервировано |
| 8 | 4 | число записей индекса, big-endian `u32` |
| 12 | 4 | размер хранилища данных, big-endian `u32` |
| 16 | 16 × n | записи: tag, type, offset, count (все big-endian `u32`) |
| … | data_size | хранилище данных |

Поддерживаемые типы: `4` INT32, `6` STRING, `7` BIN, `8` STRING_ARRAY,
`9` I18NSTRING. Строки завершаются NUL.

Заголовок сигнатуры начинается со смещения 96 (если присутствует), основной
заголовок — после него. Некоторые пакеты вставляют несколько байт выравнивания,
поэтому `detect()` ищет заголовки структурно, а не предполагает их смежность.

### Используемые теги

| Тег | Имя |
|---:|---|
| 1000–1005 | NAME, VERSION, RELEASE, EPOCH, SUMMARY, DESCRIPTION |
| 1009 | SIZE (→ `@filesize@` и `@info@`) |
| 1014, 1016, 1020, 1022 | LICENSE, GROUP, URL, ARCH |
| 1044 | SOURCERPM |
| 1047 / 1112 / 1113 | PROVIDE: имя / флаги / версия |
| 1048 / 1049 / 1050 | REQUIRE: флаги / имя / версия |
| 1053 / 1054 / 1055 | CONFLICT: флаги / имя / версия |
| 1090 / 1092 / 1091 | OBSOLETE: имя / флаги / версия |
| 1064 | **RPMVERSION** — авторитетная детекция формата |
| 1080–1082 | CHANGELOG: время / имя / текст |
| 1116–1118 | DIRINDEXES / BASENAMES / DIRNAMES |
| 1125 | PAYLOADCOMPRESSOR (gzip / xz / zstd, только для информации) |

## hdlist.cz — MDV::Packdrakeng 1.14

Формат, который пишет `packdrakeng::write_archive()`:

```
[ gzip-блок: конкатенация данных всех виртуальных файлов ]
[ TOC: по одному имени на строку ]
[ по одной 16-байтовой записи на файл ]
[ 64-байтовый трейлер ]
```

Каждый RPM добавляется как виртуальный файл типа `f`: имя — `fullname`
(`name-version-release.arch`), данные — сырой основной заголовок.

Записи TOC (`coff, csize, off, size`) — big-endian `u32`. В нашем одноблочном
архиве `coff` всегда 0, а `csize` — размер сжатого блока.

Трейлер:

| Смещение | Размер | Значение |
|---:|---:|---|
| 0 | 4 | `cz[0` |
| 4 | 4 | число каталогов (0) |
| 8 | 4 | число симлинков (0) |
| 12 | 4 | число файлов |
| 16 | 4 | длина строк TOC |
| 20 | 40 | команда распаковки, дополнена NUL (`gzip -d`) |
| 60 | 4 | `0]cz` |

`URPM.xs::open_archive()` проверяет трейлер, запускает команду распаковки из поля
и передаёт поток конкатенированных заголовков в `rpmgi`. TOC при чтении hdlist
URPM не использует — он нужен для совместимости с утилитами MDV::Packdrakeng.

## synthesis.hdlist.cz

Кодировка по `URPM.xs::Pkg_build_info()` из URPM 4.62. Один блок на пакет,
поля в строго этом порядке:

```
@provides@<объединены через @>\n
@conflicts@<объединены через @>\n
@obsoletes@<объединены через @>\n
@requires@<объединены через @>\n
@summary@<summary>\n
@filesize@<size>\n
@info@<nvra>@<epoch>@<size>@<group>\n
```

Записи зависимостей по `print_list_entry()`: `name[op evr]`, где
`op = Fstr[(flags >> 1) & 7]`, `Fstr = ["?0", "<", ">", "?3", "==", "<=", ">=", "?7"]`.
Записи с `RPMSENSE_RPMLIB` (бит 24) пропускаются, с `RPMSENSE_FIND_REQUIRES`
(бит 14) — сохраняются. Строка `@info@` всегда последняя.

Весь файл прогоняется через фильтр сжатия из `--synthesis-filter`
(по умолчанию `.cz:xz -1`).

## XML-метаданные

Корневой элемент `<media_info>`, по одному элементу на пакет:

- `<files fn="fullname">` — по одному имени файла на строку;
- `<info fn="fullname" sourcerpm="…" url="…" license="…">` — описание;
- `<changelogs fn="fullname">` — `<log time="…">` с `log_name` / `log_text`.

Каждый XML-файл сжимается фильтром `--xml-info-filter`
(по умолчанию `.lzma:xz -1`).

## Вспомогательные файлы

| Файл | Назначение |
|---|---|
| `old-rpms.lst` | INI-подобный список с секциями `[Remove]` и `[Keep-in-hdlist]` |
| `old-metadata.lst` | устаревшие записи метаданных для режима merge |
| `UPDATING` | глобальная блокировка `flock` |
| `MD5SUM` | контрольные суммы опубликованных метаданных |
| `YYYYMMDD-HHMMSS-<name>` | версионированные симлинки на актуальные файлы |
